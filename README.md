## Realtime & Sync Backends

- [Convex](https://convex.dev/) - Backend platform with reactive database, serverless functions, and realtime updates. Uses TypeScript for backend logic and automatically syncs state to clients without manual API endpoints. ([Read more](/details/convex.md)) `Managed` `Free Plan` `API` `TypeScript` `Realtime` `Freemium`
- [Hasura](https://hasura.io/) - GraphQL engine that connects to databases and instantly generates GraphQL APIs with realtime subscriptions and authorization. Supports PostgreSQL, SQL Server, BigQuery, and other data sources. ([Read more](/details/hasura.md)) `Managed` `Free Plan` `API` `GraphQL` `Enterprise` `Freemium`
- [InstantDB](https://instantdb.com/) - Realtime database and authentication layer for React applications with local-first sync and optimistic updates. Eliminates traditional API layer by connecting frontend directly to database with permissions. ([Read more](/details/instantdb.md)) `Managed` `Free Plan` `API` `Realtime` `React` `Freemium`
- [Turso](https://turso.tech/) - Edge-distributed libSQL database platform based on SQLite with replication and branching. Designed for low-latency data access close to users with embedded database capabilities. ([Read more](/details/turso.md)) `Managed` `Free Plan` `API` `SQLite` `Edge` `Freemium`

## Self-Hostable

- [Appwrite](https://appwrite.io/) - Self-hosted backend server offering databases, authentication, storage, functions, and messaging via REST APIs. - [Directus](https://directus.io/) - Open data platform wrapping SQL databases with dynamic API, admin app, and content management tools. Supports MySQL, PostgreSQL, and other SQL flavors with self-hosted and cloud options. ([Read more](/details/directus.md)) `Open Source` `Self-Hosted` `Free Plan` `API` `Headless CMS`
- [Parse Server](https://parseplatform.org/) - Open source backend framework that can be deployed on any infrastructure supporting Node.js. Provides database adapters, authentication, push notifications, and cloud code for migrating from Parse.com.
